|GREEK++ COMPILER|

|DESCRIPTION|

This project implements a compiler for the educational programming language **greek++**.  
The compiler reads a `.gr` source file written in greek++ and translates it into an equivalent **assembly (.asm)** file.  
It is part of the **“Μεταφραστές” (Compilers)** course at the **University of Ioannina**.  

The compiler performs:
- Lexical analysis (tokenizing the source code)
- Syntax and semantic analysis (validating program structure and logic)
- Code generation (producing assembly output)

|HOW TO RUN|

-> **Requirements:** Python 3.8 or higher installed on your system  

-> **How to run:**  
1. Place your greek++ source file (e.g., `program.gr`) in the project folder.  
2. Open a terminal in the project directory.  
3. Run the compiler using the command:  `compiler.py test.gr`
